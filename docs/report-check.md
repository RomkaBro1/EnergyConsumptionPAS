## Воспроизведение сборки

Дополнительные зависимости устанавливаются отдельно от приложения:

```powershell
python -m pip install -r requirements-docs.txt
python tools/build_report.py
.\tools\render_report.ps1 -InputDocument .\docs\report.docx -OutputPdf .\docs\report.pdf -Update
python tools/check_report.py
```

Для экспорта требуется установленный Microsoft Word в Windows. Он запускается скрыто; исходный титульный документ используется только для чтения. Повторная сборка заменяет итоговые файлы, поэтому ручные изменения следует вносить в `docs/report.md` либо заранее сохранять отдельной копией.

Снимки воспроизводятся командой `python tools/capture_report.py` при работающем локальном сайте. Пересъёмка на другой дате может изменить показанные прогнозы и предупреждения о свежести; после неё следует обновить подписи даты в исходном тексте. Старый общий генератор `tools/build_documents.py` теперь использует тот же оформленный сборщик отчёта.
